# Purpose

The Reporting Engine transforms engineering results into human-readable documents.

Reporting is the final stage of the software.

The Reporting Engine never performs engineering calculations.

The Reporting Engine never modifies stored data.

It is a presentation layer.

---

# Design Philosophy

Report = Snapshot

A report represents the state of one completed test at one specific moment.

Generating a report shall never change

Measurements

Mechanical Properties

Acceptance

Material

Test Method

Order
