# Purpose

This chapter defines the complete Report Generation Architecture of the Universal Testing Machine (UTS).

The Report Engine is responsible for transforming engineering data into official laboratory documents.

The generated report is the final deliverable of the testing process.

---

# Philosophy

A report is a **representation** of engineering data.

It never generates engineering data.

It never recalculates engineering properties.

It never evaluates acceptance.

```
Engineering Data

↓

Report Engine

↓

Official Report
```

# Design Constraints

Report Engine SHALL NOT

Perform Engineering Calculations

Evaluate Acceptance

Modify Measurements

Modify Mechanical Properties

Communicate with PLC

Control Machine Motion

---

# Architectural Decision (FROZEN)

The Report Engine is the **only subsystem responsible for producing official laboratory documents**.

Reports shall always be generated from finalized engineering data and approved acceptance results.

No report template shall contain engineering logic or acceptance logic.

Reports are presentation artifacts only.

This decision is permanent.
