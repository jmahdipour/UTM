## Why this matters beyond the wiring content

This is the first document in the repository to independently confirm the
physical machine's OEM lineage: **Shimadzu Autograph AG-A Series**. This explains
the "Autograph" naming throughout the legacy VB.NET codebase and Visual Studio
project (`Autograph.zip`, `Autograph_SVR.fcs`, `MDIParent`, etc.) and the `AG01`
folder/analysis name used since the earliest legacy ingestion in this repository —
neither name was previously traced to a specific OEM machine family.

It is legacy/reference evidence only, not authoritative. See
`SHIMADZU_EXTENSOMETER_MANUAL_REVIEW.md` for controlled findings.
