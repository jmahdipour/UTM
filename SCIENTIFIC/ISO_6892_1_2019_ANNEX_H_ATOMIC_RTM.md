# ISO 6892-1:2019 Atomic RTM - Annex H

## Control statement

This inventory paraphrases informative Annex H of the controlled English third edition. It does not reproduce the standard. Printed-page and PDF-page locators identify the controlled local source. Annex H provides precautions and one recommended manual method when the specified elongation-after-fracture value is below 5 percent; it does not create an independent conformity requirement or make its method exclusive.

`EXTRACTED / REVIEW-PENDING` means that the source item is independently addressable and cross-linked, but its interpretation and parameterization have not received independent scientific sign-off. No row is implementation, validation execution or conformity evidence.
